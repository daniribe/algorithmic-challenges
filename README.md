## Problems

### Binary Dataset Balance

Given two binary strings, determine the minimum number of removals required so that the merged result contains the same number of `0`s and `1`s.

Topics:

- Strings
- Greedy
- Prefix/Suffix processing
- Hash Map

Complexity:

```txt
Time: O(n)
Memory: O(n)
```

---

### Processing Interval Queries

Given process execution intervals and multiple queries, determine how many seconds contain exactly `k` running processes inside a time range.

Topics:

- Sweep Line
- Difference Array
- Prefix Sum
- Binary Search

Complexity:

```txt
Time: O(n + MAX + q log MAX)
Memory: O(MAX)
```
